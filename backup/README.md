# 할일장 읽기 전용 데이터 백업 도구

이 브랜치는 **기존 할일장의 JavaScript나 화면을 변경하지 않습니다.** `backup/` 폴더의 새 페이지 파일만 추가합니다.

## 백업 진행 방법

1. 안전한 검토를 마치고 **이 백업 전용 브랜치의 파일만** 기존 사이트와 동일한 출처(origin)에 게시합니다. 개발 중인 음성 기능 전체를 배포하지 않습니다.
2. 기존 할일장 사이트의 `/backup/` 경로를 엽니다. (구체 URL은 실제 운영 도메인을 확인한 뒤 안내)
3. 기존 할일장 Firebase 계정으로 로그인합니다. 이 페이지는 기존 할일장 초기화 코드를 실행하지 않습니다.
4. '기존 내용 백업 파일 다운로드'를 누릅니다.
5. 브라우저 다운로드 폴더에 `haliljang-backup-YYYY-MM-DD-XXXXXX.json`이 생성됐는지 직접 확인합니다.
6. 내용 확인: JSON의 `userDocument.tasks`, `userDocument.worklist`, `userDocument.notes`와 `subcollections.bookings`.
7. 백업 파일을 외장 드라이브 등 별도 저장 공간에도 안전하게 보관합니다. 파일에 개인 정보가 있으므로 공개 GitHub 저장소에 올리지 마세요.

## 보안/안전

- Firebase Authentication으로 **본인 계정**으로만 로그인합니다.
- Firebase Firestore SDK의 읽기 함수(`getDoc`, `getDocs`)만 사용합니다.
- 기존 앱의 변경/삭제 코드나 자동 이월 기능이 실행되지 않습니다.
- `chatgptTasks`가 현 보안 규칙으로 읽히지 않아도 기존 사용자 문서·예약은 백업합니다. 경고 문구를 JSON 및 화면에 기록합니다.
- Firestore 규칙은 변경하지 않습니다.
- 단, 이것은 확인된 문서/하위 컬렉션만 담는 **사용자 데이터 JSON 복사본**이며, 숨겨진 다른 컬렉션까지 포함하는 관리자 전체 내보내기를 대신하지 않습니다.
- Firestore 읽기 자체가 실패하면 다운로드 완료로 표시하지 않습니다.

**중요:** 이 도구는 지금 개발 브랜치에만 존재합니다. 실제 Firebase 데이터는 아직 백업되지 않았습니다.
